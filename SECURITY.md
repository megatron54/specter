# Security Policy

## Scope

Specter is a network reconnaissance and security-testing tool intended
**exclusively for authorized security testing** on networks and devices you own
or have explicit, written permission to assess. Any other use may be illegal.
See the Ethical Use & Disclaimer section of the README for full details.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately by email:

- **miguel.serra.ferrando@gmail.com**

Please include a description of the issue, steps to reproduce, and any relevant
proof-of-concept details. Avoid opening public issues for undisclosed
vulnerabilities.

## No Bug Bounty

This is a personal, open-source project maintained on a best-effort basis.
There is **no bug bounty program** and no financial reward for reports.
Responsible disclosure is nonetheless greatly appreciated.
